# Questions for the pggb authors

Written in 2026-11 under the placement question
(`../waiting-on-a-call/pggb-placement-rule.md`). Nobody has sent them.

- Would they publish `odgi untangle` projections of HPRC release 2's pggb
  graphs against GRCh38 and CHM13? Release 2 ships no projection of its
  pggb graphs, only the wfmash all-vs-1 alignments
- Is a chain-based single-copy projection, as
  `docs/departures/scripts/primary.py` builds from those alignments, what
  they would endorse for a browser?
- How would they want sequence shown that matches several copies: at one
  copy, at every copy, or as present with its copy unresolved?

An answer to the last bears on "Showing every copy" in the placement file,
which stays open until then.
